# Auction Pricing Simulation

Simulates an auction-style price discovery mechanism based on randomly generated order books using Python and visualizes the resulting auction prices and volumes over time.

---

## Overview

The core idea is to:
- Simulate **bid** and **ask** order books around a reference price.
- Determine a **single auction price** that maximizes matched volume.
- Repeat this process over multiple iterations to visualize price and volume trends.
